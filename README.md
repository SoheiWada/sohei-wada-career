# 和田壮平 Career Portfolio LP refined v2

`index(6).html` をベースに、最終デザインの温かいトーンを残しながら、BtoBポートフォリオとして外部共有しやすいように整えた版です。

## 調整内容

- 既存の内容・構成は大きく変更せず、職務経歴書の補足資料としての読みやすさを優先
- 見出しの折り返し、行間、文字詰めを調整
- カードの角丸・影・罫線を抑え、ビジネス資料としての信頼感を強化
- ヒーロー内の数値カードを表形式に近づけ、入れ子カード感を軽減
- Hero / Positioning / Profile / Philosophy を、一気通貫で推進できる人材として伝わる文言へ調整
- 清流公園は先方共有方針に合わせ、事業提案・契約交渉・運営スキーム構築の実績として要約掲載
- ホテル婚礼向け演出商品LP・申込管理フロー構築の実績をProjectsに補足追加
- 職務経歴書PDFを同梱し、LP上からダウンロードできる導線を追加
- `noindex,nofollow,noarchive` と `robots.txt` により検索避けを設定
- モバイル表示でCTA、数値、プロジェクトカードが自然に縦積みされるよう調整

## 表示方法

`index.html` をブラウザで直接開いて確認できます。
