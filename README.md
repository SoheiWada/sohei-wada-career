# 和田壮平 Project Portfolio

応募先企業への提出用ポートフォリオ。制作チームのマネジメントと業務の仕組みづくりを軸に、Web制作・業務改善・クリエイティブの実績を紹介します。

## 公開ページ

https://soheiwada.github.io/sohei-wada-career/

GitHub Pagesは`main`ブランチのルートにある`index.html`を公開します。

## 構成

- `index.html`：スタイル・画像・職務経歴書PDFを内包した単体HTML
- `robots.txt`：検索エンジン向けのクロール除外設定

PC・スマートフォンに応じてレイアウトが切り替わります。職務経歴書PDFはページ内のダウンロードボタンから取得できます。

## 公開範囲について

検索除外用のメタタグと`robots.txt`を設定していますが、アクセス制限ではありません。ページおよびこのリポジトリは公開されています。

## 更新

`index.html`を更新して`main`へプッシュすると、GitHub Pagesへ反映されます。画像やPDFはHTML内に埋め込まれているため、更新時はHTML本体を含めて確認してください。
