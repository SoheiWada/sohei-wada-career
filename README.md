# 和田壮平 Project Portfolio

応募先企業への提出用ポートフォリオ。現場の声を起点に、制作・チーム運営・業務設計をつなぐ実績を紹介します。

## 公開ページ

https://soheiwada.github.io/sohei-wada-career/

GitHub Pagesは `main` ブランチのルートを公開します。

## 構成

- `index.html`：本文とプロジェクトの構成
- `assets/portfolio-v12/`：スタイル、動き、画像、共有カード、職務経歴書PDF
- `robots.txt`：検索エンジン向けのクロール除外設定
- `.nojekyll`：静的ファイルをそのまま配信する設定

PC・スマートフォンに応じて表示が切り替わります。画像とPDFは別ファイルで配信し、ページ外のアニメーションは停止します。動きを止めるボタン、動きを減らす端末設定、キーボード操作に対応しています。職務経歴書PDFは通常のリンクから取得できます。

CASE内では現在地を示すナビから各事例へ移動できます。THEATER010の実物写真は拡大でき、閉じると元の操作位置へ戻ります。

## 公開範囲

検索除外用のメタタグと `robots.txt` を設定していますが、アクセス制限ではありません。このページとリポジトリは公開されています。

## 更新

`index.html` と参照先の `assets/` をまとめて更新してください。共有カードやアイコンも `assets/` に含まれます。
