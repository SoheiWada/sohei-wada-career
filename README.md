# 和田壮平 Project Portfolio

応募先企業への提出用ポートフォリオ。現場の声を起点に、制作・チーム運営・業務設計をつなぐ実績を紹介します。

## 公開ページ

https://soheiwada.github.io/sohei-wada-career/

GitHub Pagesは `main` ブランチのルートを公開します。

## 構成

- `index.html`：本文とプロジェクトの構成
- `assets/portfolio-v12/`：スタイル、動き、画像、共有カード、職務経歴書PDF
- `robots.txt`：検索エンジン向けのクロール除外設定
- `.nojekyll`：静的ファイルをそのまま配信する設定

PC・スマートフォンに応じて表示が切り替わります。画像とPDFは別ファイルで配信し、ページ外のアニメーションは停止します。動きを止めるボタン、動きを減らす端末設定、キーボード操作に対応しています。職務経歴書PDFは通常のリンクから取得できます。

CASE内では現在地を示すナビから各事例へ移動できます。THEATER010の実物写真は拡大でき、閉じると元の操作位置へ戻ります。

## 公開範囲

検索除外用のメタタグと `robots.txt` を設定していますが、アクセス制限ではありません。このページとリポジトリは公開されています。

## 更新

`index.html` と参照先の `assets/` をまとめて更新してください。共有カードやアイコンも `assets/` に含まれます。

### 2026年10月26日

大会を開いた理由と、構想から実現へ進む姿勢を追記しました。`possibility-v13.css` と `possibility-v13.js` が、既存の黄色い光とリボンの表現を引き継ぐ2つの概念アニメーションを担当します。各場面は3段階で切り替わり、ボタンを押すと自動切り替えを停止します。画面外・非表示タブ・全体の停止設定・端末の動きを減らす設定では自動再生しません。JavaScriptが使えない場合も最終状態と説明を表示します。

プロフィールの担当範囲をホテル常駐の音響・照明・映像部門と明記し、職務経歴書リンクを `sohei-wada-resume-20261026-general.pdf`（汎用版）へ更新しました。


### プロフィールの構想アニメーション

`possibility-v14.css` と `possibility-v14.js` を使用。一つの点が巡って関係を結び、つながった先に新しい点が芽生え、曲線の立体的な場へ整う4段階の表現に変更しました。大会の3段階アニメーションは維持しています。プロフィールは表示中だけ描画し、画面外・非表示タブ・全体の停止設定で停止します。端末の動きを減らす設定とJavaScript無効時は完成した形を表示します。各段階のボタンでは静止して説明を読み、「もう一度見る」で最初から再生できます。

### 光の始まりと、自走を支える巡回

`possibility-v15.css` と `possibility-v15.js` に更新。最初の光には集まって芯になる細い光と呼吸を加え、冒頭を4.2秒に調整しました。03以降も最初の光が仲間の点を巡り続け、新しく生まれた点は各自の小さな軌道で動きます。段階のボタンは進行のみを固定し、その段階の穏やかな動きと説明を維持します。全体の停止設定・端末の動きを減らす設定・画面外・非表示タブでは描画を停止します。

### ページ全体の余白と読み進める流れ

`reading-rhythm-v16.css` で、ヒーロー・実績・大会・マネジメント・プロフィール・職務経歴書の間隔を調整しました。概念アニメーションと文章を上端でそろえ、SVG本来の縦横比で表示。マネジメント紹介の末尾に確保していた長いスクロール余白を取り除き、次のプロフィールまでの流れをつなげています。本文の文字サイズは維持し、印刷用スタイルには適用しません。
